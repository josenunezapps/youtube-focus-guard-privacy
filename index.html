Política de privacidad

YouTube Focus Guard · Última actualización: 17 de julio de 2026

YouTube Focus Guard es una extensión diseñada para reducir distracciones dentro de YouTube mediante el bloqueo de Shorts, recomendaciones, comentarios, palabras, canales y búsquedas configuradas por el usuario.

Datos procesados

La extensión procesa localmente contenido visible en YouTube, como títulos de videos, nombres de canales y términos de búsqueda, únicamente para aplicar los filtros elegidos por el usuario.

También guarda la configuración seleccionada por el usuario, incluyendo el estado de Bloquear Shorts, Modo Enfoque, palabras bloqueadas, canales bloqueados y estadísticas básicas de elementos bloqueados.

Almacenamiento

Las preferencias se guardan mediante las APIs de almacenamiento de Chrome. Las opciones principales pueden almacenarse en chrome.storage.sync y las estadísticas básicas en chrome.storage.local. Estos datos permanecen bajo el control del navegador y no se envían a servidores del desarrollador.

Datos que no se recopilan

  • No se recopilan nombres, direcciones, correos ni datos de identificación.
  • No se recopilan datos financieros, de salud, autenticación o ubicación.
  • No se registra el historial completo de navegación.
  • No se registran teclas, clics ni movimientos del mouse.
  • No se utilizan herramientas de análisis, publicidad ni seguimiento.

Uso y transferencia de datos

Los datos procesados se utilizan exclusivamente para proporcionar las funciones de YouTube Focus Guard. No se venden, alquilan, comparten ni transfieren a terceros, y no se utilizan para publicidad, solvencia, actividades crediticias ni finalidades ajenas al propósito de la extensión.

El uso de la información por parte de YouTube Focus Guard cumple con la Política de Datos de Usuario de Chrome Web Store, incluidos los requisitos de Uso Limitado.

Permisos

La extensión solicita el permiso storage para conservar la configuración y acceso únicamente a https://www.youtube.com/* para aplicar los filtros dentro de YouTube.

Eliminación de datos

El usuario puede eliminar palabras y canales desde el popup, reiniciar las estadísticas o desinstalar la extensión. También puede borrar los datos de la extensión desde la configuración de Chrome.

Cambios en esta política

Esta política puede actualizarse si cambian las funciones o prácticas de datos de la extensión. La fecha de actualización se indicará al comienzo de esta página.
