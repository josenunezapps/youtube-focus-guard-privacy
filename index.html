Política de privacidad

DistraGuard · Última actualización: 24 de julio de 2026

Descripción general

DistraGuard es una extensión diseñada para reducir distracciones y permitir que el usuario controle el contenido que aparece dentro de YouTube.

Entre sus funciones se incluyen el bloqueo de Shorts, palabras y canales, el Modo Enfoque, el ocultamiento individual de videos, la pausa temporal de las protecciones y el bloqueo de la configuración mediante contraseña.

Datos procesados

DistraGuard procesa localmente información visible en YouTube únicamente para aplicar las funciones elegidas por el usuario. Esto puede incluir:

  • títulos e identificadores de videos;
  • nombres de canales;
  • términos de búsqueda;
  • elementos visibles de la interfaz de YouTube.

La extensión también guarda los datos introducidos o seleccionados por el usuario, entre ellos:

  • palabras bloqueadas;
  • canales bloqueados;
  • estado de Bloquear Shorts;
  • estado del Modo Enfoque;
  • estado de la pausa general;
  • videos ocultos individualmente;
  • identificador, título y canal de los videos ocultos;
  • estadísticas básicas de elementos bloqueados;
  • estado abierto o cerrado del candado.

Esta información se utiliza exclusivamente para proporcionar las funciones visibles de DistraGuard.

Contraseña y candado

Cuando el usuario crea una contraseña para proteger la configuración, la contraseña original se utiliza únicamente en el dispositivo para generar un verificador seguro.

DistraGuard no guarda la contraseña original en texto visible.

La extensión almacena localmente:

  • una sal aleatoria;
  • un verificador derivado mediante PBKDF2 con SHA-256;
  • los parámetros técnicos necesarios para comprobar posteriormente la contraseña.

Esta información no permite que DistraGuard muestre o recupere la contraseña original.

Si el usuario olvida la contraseña, puede restablecer DistraGuard. Este proceso elimina la contraseña, las configuraciones, las listas, los videos ocultos y las estadísticas guardadas.

Almacenamiento

DistraGuard utiliza las API de almacenamiento de Chrome.

Las preferencias generales, como Shorts, Modo Enfoque, pausa, palabras y canales bloqueados, pueden guardarse mediante chrome.storage.sync. Chrome puede sincronizar estas preferencias entre navegadores en los que el usuario haya iniciado sesión con la misma cuenta.

Las estadísticas, los videos ocultos, el estado del candado y el verificador de la contraseña se guardan mediante chrome.storage.local.

El desarrollador no posee servidores que reciban o almacenen estos datos.

Datos que no se recopilan

DistraGuard:

  • no recopila nombres, direcciones, correos electrónicos ni otros datos de identificación personal;
  • no recopila información financiera, médica o de ubicación;
  • no guarda la contraseña original;
  • no registra el historial completo de navegación;
  • no registra pulsaciones de teclado, movimientos del mouse ni actividad fuera de las funciones propias de la extensión;
  • no utiliza herramientas de análisis o seguimiento;
  • no utiliza publicidad personalizada;
  • no ejecuta código remoto;
  • no envía la configuración ni el contenido procesado a servidores del desarrollador.

Uso y transferencia de datos

Los datos procesados se utilizan exclusivamente para proporcionar las funciones visibles de DistraGuard.

Los datos:

  • no se venden;
  • no se alquilan;
  • no se comparten con anunciantes;
  • no se transfieren a intermediarios de datos;
  • no se utilizan para evaluar solvencia o realizar actividades crediticias;
  • no se utilizan para finalidades ajenas al propósito de la extensión;
  • no son leídos por el desarrollador ni por otras personas.

El uso de la información por parte de DistraGuard cumple con la Política de Datos de Usuario de Chrome Web Store, incluidos los requisitos de Uso Limitado.

Permisos

storage

Se utiliza para conservar las configuraciones, listas, videos ocultos, estadísticas, estado del candado y datos derivados de la contraseña.

Acceso a https://www.youtube.com/*

Se utiliza exclusivamente para analizar la interfaz visible de YouTube y aplicar los bloqueos, ocultamientos y protecciones seleccionados por el usuario.

DistraGuard no utiliza este acceso para recopilar ni enviar el historial de navegación.

Eliminación de datos

El usuario puede eliminar datos desde el popup de DistraGuard mediante las opciones disponibles para:

  • quitar palabras bloqueadas;
  • quitar canales bloqueados;
  • mostrar todos los videos ocultos;
  • reiniciar estadísticas;
  • restablecer completamente la extensión si olvidó la contraseña.

También puede borrar todos los datos desinstalando DistraGuard o eliminando sus datos desde la configuración de Chrome.
